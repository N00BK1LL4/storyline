# gm_chimera

The Chimera boss from OPEN//77's `open77_chimera` (MIT), with two additions for Storyline,
marked `LOCAL ADDITION` in `server.lua`: staff ghost mode, and holding a beaten boss down.

Load it instead of `open77_chimera`, not next to it. Every player fighting the Chimera needs
Phantom Liberty. Please report problems to Storyline, not to the OPEN//77 project.
